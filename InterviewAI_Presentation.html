Introduction
What is the AI Virtual Interview Platform?

An AI-based platform designed to simulate a realistic, interactive interview — combining Generative AI, Speech Recognition, and Computer Vision to give candidates a comprehensive practice experience.

📄
Resume-Driven Questions: System parses candidate resume and generates personalized interview questions.
🎙️
Voice-Based Answering: Candidates answer verbally. Whisper ASR converts speech into accurate text.
🧠
AI Answer Evaluation: Qwen3-8B LLM evaluates response quality and generates adaptive follow-up questions.
😊
Facial Emotion Analysis: FERPlus ONNX model detects 7 emotion categories from webcam in real time.
📊
Performance Report: Comprehensive scores, emotion data, strengths, weaknesses and improvement roadmap.

Problem Statement & Objectives
Existing Problems & Proposed Objectives
⚠️ Existing Problems

Candidates have limited access to realistic interview practice environments.

Manual interview evaluation is time-consuming and often subjective.

Candidates do not receive immediate, structured feedback after sessions.

Difficult to evaluate both verbal and non-verbal behavior simultaneously.

Generic question sets with no personalization based on the candidate's resume.

No system to track emotion, eye contact or communication quality during practice.

✅ Proposed Objectives
01

Automate the interview process using AI-driven question generation and evaluation.

02

Generate personalized questions based on the candidate's resume and skills.

03

Convert speech to text using Whisper-large-v3-turbo ASR model.

04

Evaluate answers using Qwen3-8B for relevance, depth and technical accuracy.

05

Analyze facial emotions from webcam frames using FERPlus ONNX model.

06

Measure eye-contact behavior using OpenCV Haar Cascade detection.

07

Generate a comprehensive report with scores, feedback, and study roadmap.

AI Models & Technology Stack
AI Models & Technology Stack
PRIMARY LLM

Qwen/Qwen3-8B

Primary LLM — interview question generation, answer evaluation, counter-questioning, resume analysis and feedback.

FALLBACK LLM

Qwen/Qwen3-4B

Fallback LLM used when the primary Qwen3-8B model is unavailable or fails to respond.

LOCAL LLM

Ollama Qwen2.5:7B

Local/offline LLM for development environments without internet connectivity.

SPEECH

openai/whisper-large-v3-turbo

Automatic Speech Recognition — converts candidate voice into accurate text transcripts.

EMBEDDINGS

BAAI/bge-small-en-v1.5

Semantic embedding model — measures answer relevance using cosine similarity scoring.

COMPUTER VISION

FERPlus ONNX + OpenCV Haar Cascades

CNN facial emotion recognition (7 classes) + face, eye and smile detection.

Analysis Pipelines
Speech & Emotion Analysis Pipelines
🎙️ Section A — Speech Analysis Pipeline
👤 Candidate Speaks into Microphone
↓
🎵 Web Audio API captures raw audio stream
↓
📦 Converted to 16 kHz / 16-bit / Mono WAV
↓
🔌 Sent via WebSocket to FastAPI Backend
↓
🧠 Whisper-large-v3-turbo — ASR Transcription
↓
📝 Text Transcript → Qwen3-8B Answer Evaluation
Fallback: Browser Web Speech API used if Whisper API is unavailable.
📷 Section B — Facial Emotion Analysis Pipeline
📷 Webcam Frame captured every 1.5 seconds
↓
🔲 OpenCV Haar Cascade — Face Detection
↓
✂️ Face ROI Extracted → Grayscale Conversion
↓
📐 Resized to 64×64 pixels for CNN input
↓
🤖 FERPlus ONNX CNN — Emotion Probabilities
↓
👁️ Haar Eye Cascade → Eye-Contact Score 0–100%

Conclusion & Future Scope
Conclusion
🤖

Combines Generative AI (Qwen3), Speech Recognition (Whisper), Semantic Analysis (BGE) and Computer Vision (FERPlus + OpenCV) in one integrated platform.

🎯

Provides a realistic, personalized and interactive interview experience based on the candidate's own resume and responses.

🎙️

Whisper ASR enables natural voice-based interaction without manual text entry.

😊

Emotion and eye-contact analysis provide behavioral insights beyond verbal content — a unique multi-modal evaluation.
